# MetroFlow — 北京地铁客流量可视化分析系统

## 项目概述

基于北京地铁 SVG 线路图，将 28 条线路 × 2019-2025 年共 2498 天 × 每日 18 小时 × 双向（进城/出城）的客流数据，通过**线宽编码**、**Viridis 色觉友好配色**、**潮汐剪刀差图**、**时间轴动画**、**网络级联联动**等多维可视化手段，构建一个纯前端的交互式客流分析系统。

## 技术栈

纯前端 SPA：HTML + CSS + 原生 JavaScript + Canvas，无框架依赖。通过 `python -m http.server` 即可本地运行。

## 核心功能详解

### 1. 四模式时间粒度

| 模式 | 选择器 | 展示内容 | 播放范围 | 序列长度 |
|------|--------|---------|---------|---------|
| 年 | 年份下拉框 | 某年全线路客流量 | 历年年份（2019-2025） | 7 |
| 月 | 年份下拉框 | 某月全线路客流量 | 当年 1-12 月 | 12 |
| 日 | 月份选择器 | 某日全线路客流量 | 当月每一天 | 28-31 |
| 时 | 日期选择器 | 当日某小时客流量 | 5:00-23:00 | 18 |

### 2. 六档线宽编码（Viridis 色觉友好配色）

基于当日 28 条线路客流值的等分位（20/40/60/80 百分位），将线路分为六档：

| 档次 | 含义 | 线宽 | 颜色 | 说明 |
|------|------|------|------|------|
| 1 | 很低 | 0.5px | 紫 #440154 | 客流最低的 20% |
| 2 | 较低 | 2px | 蓝 #3b528b | |
| 3 | 中等 | 5px | 青 #21918c | |
| 4 | 较高 | 13px | 绿 #5ec962 | |
| 5 | 很高 | 26px | 黄 #fde725 | 客流最高的 20% |
| 6 | **最高** | **36px** | 橙 #ff8800 | 当日/月/年/时客流**第一**独占 |

- tier 6（最高客流线）额外叠加 `stroke-dasharray="40,3"` 虚线双编码，色盲友好
- 所有线路路径端点圆角（`stroke-linecap="round"`）

### 3. 时间轴播放与进度条拖拽

- **播放控制**：▶ 播放 / ⏸ 暂停 / ⏮ 后退 / ⏭ 前进
- **速度调节**：0.5x / 1x / 2x / 4x（2000ms ~ 250ms/帧）
- **拖拽进度条**：点击或拖拽蓝色圆点手柄可跳转到任意帧，拖拽时自动暂停、松手恢复播放
- **渲染优化**：播放期间暂停排名列表刷新（每帧仅更新 SVG 地图和图例），暂停时一次性更新排名

### 4. 潮汐剪刀差图（时模式专属）

时模式下，地图上方显示 Canvas 绘制的双向客流折线图：

- **蓝色线** = inbound（进城方向）
- **橙色线** = outbound（出城方向）
- X 轴 = 18 个时段（5:00-23:00），Y 轴 = 客流量（万人次）
- 早高峰 inbound 冲高、晚高峰 outbound 冲高，形成经典"剪刀"形态
- **点击排名列表中的任意线路**即可切换图表为该线路的双向数据
- 图例标注 "inbound 进城" / "outbound 出城"

### 5. 排名列表（带潮汐方向标签 + Sparkline）

地图下方列出当日 28 条线路的客流量排名（从高到低）：

- 名次（前 3 名金色高亮）
- 线路名
- 水平柱状图（宽度与当日最大值成比例，颜色匹配六档分类）
- 客流量数值（万）
- 六档颜色圆点
- **潮汐方向标签**（日/时模式）：`↑ 进城` / `↓ 出城` / `↔ 均衡`
- **Sparkline 趋势线**（日/时模式）：每条线路末尾 80×20 迷你 Canvas 折线，展示当日 18 小时客流波动，峰值点标记

### 6. 场景标签

标题下方自动显示当前日期的场景上下文：

- 日期属性：工作日 / 周末 / 长假·春节 / 返程高峰 / 节前离京
- 天气因子：降雨（蓝色标签）、降雪（白色标签）
- 突发事件：如"五棵松演唱会散场"（红色标签）

年/月模式下不显示。

### 7. 换乘站标注

SVG 地图上自动检测被 ≥3 条线路经过的换乘站，用白圈蓝边的大圆点标注。鼠标悬停弹出 tooltip：

> 换乘站 · 4条线路
> 1号线-八通线  2号线  6号线  10号线

### 8. 地图 ↔ 排名双向联动（网络级联悬浮）

- **地图 → 排名**：hover 地图线路时：
  - hover 线路保持 100% 亮度
  - 与其直接换乘的线路（1-hop）保持 50% 亮度
  - 无连接线路 dim 至 10%
  - 排名中对应行同步高亮
- **排名 → 地图**：hover 排名行时，地图线路同理三级 dimming
- 换乘邻接关系由 `transferStations.js` 的 `getLineAdjacency()` 自动从 SVG 站点坐标构建

### 9. 地图线路悬停 Tooltip

鼠标悬停地图线路时弹出详情卡片，显示线路名称、当日客流量、当前排名、排名变化（↑↓─）。

### 10. 小多图（Small Multiples）

点击控制栏「小多图」按钮，地图上方出现 7×4 CSS Grid，每格一条线路的迷你潮汐图（蓝色=inbound，橙色=outbound），一眼扫过 28 条线路的双向客流形态。播放时自动刷新。

### 11. 山脊图（Ridgeline Plot）

点击控制栏「山脊图」按钮，打开全屏 Canvas 叠加层。28 条线路的客流曲线按垂直偏移堆叠如层峦，直观对比各线路在 18 小时内的拥堵分布。

### 12. 空间粒子流动

tiers 3-5 的线路上自动叠加流动虚线粒子效果。粒子沿主导客流方向移动（基于 7:00-8:00 inbound/outbound 比例），流速与客流大小成正比。纯 CSS 动画驱动，零性能损耗。

## 数据维度

| 维度 | 字段 | 取值 |
|------|------|------|
| 时间 | date + 5:00-23:00 | 7年 × 12月 × 28-31天 × 18小时 |
| 线路 | lines（28条） | 1号线-八通线 ~ 大兴机场线 |
| 方向 | inbound / outbound | 进城 vs 出城 |
| 场景 | day_type | normal(1647) / weekend(653) / holiday(93) / return(63) / exodus(42) |
| 扰动 | weather + event | rain(364) / snow(124) / 演唱会赛事(183) |

## 数据聚合逻辑

- **时模式**：直接读取 JSON 中对应 hour slot 的 `inbound`/`outbound`/`total` 值
- **日模式**：对该日 18 个 hour slot 的 `total` 求和
- **月模式**：对该月所有日 `total` 求和
- **年模式**：对该年所有日 `total` 求和

## 共线处理

- 13号线与18号线共享 SVG 轨道组 `L13_L18`（物理共线），渲染时取两者客流较大值
- 房山线与燕房线共享 `房山_燕房线`，同理

## 技术亮点

- **rAF 解耦渲染**：播放时定时器只负责调度，实际渲染在 `requestAnimationFrame` 中完成，暂停/拖拽即时响应
- **播放期间增量渲染**：仅更新 SVG 线宽和图例，排名列表延迟到暂停后一次性刷新，保证 250ms/帧的流畅度
- **换乘站自动检测**：扫描全部 28 个 SVG 线路组的站点圆坐标，取整聚类后筛选 ≥3 次出现的位置
- **polyline + path 双兼容**：潮汐图和换乘站检测均支持 `<path>`（`getPointAtLength`）和 `<polyline>`（手动分段插值）
- **网络级联邻接表**：从 SVG 站点坐标自动构建线路换乘关系图，无需外部数据
- **Viridis 色觉友好配色**：六档颜色从紫到黄顺序映射，确保亮度和色相单调递增，色盲友好
- **tier 6 双编码**：最高客流线同时使用最大线宽 + 虚线模式，颜色与形状双重区分
