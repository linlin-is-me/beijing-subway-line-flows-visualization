# MetroFlow — 北京地铁客流量可视化分析系统

## 项目概述

基于北京地铁 SVG 线路图，将 28 条线路 × 2019-2025 年共 2498 天 × 每日 18 小时 × 双向（进城/出城）的客流数据，通过**线宽编码**、**橙红暖色渐变配色**、**潮汐剪刀差图**、**时间轴动画**、**去饱和联动**等多维可视化手段，构建一个纯前端的交互式客流分析系统。

## 技术栈

纯前端 SPA：HTML + CSS + 原生 JavaScript + Canvas，无框架依赖。通过 `python -m http.server` 即可本地运行。

## 核心功能详解

### 1. 四模式时间粒度

| 模式 | 操作 | 序列 |
|------|------|------|
| 年 | 日期选择器选年份，遍历 2019-2025 | 7 年 |
| 月 | 日期选择器选月份，遍历当年 1-12 月 | 12 月 |
| 日 | 日期选择器选日期，遍历当月每一天 | 28-31 天 |
| 时 | 日期选择器选日期 + 进度条遍历 5:00-23:00 | 18 时段 |

单一 `<input type="date">` 控件 + 模式按钮（年/月/日/时）统一切换。

### 2. 六档线宽编码（橙红暖色渐变）

基于当前 28 条线路客流值的等分位（20/40/60/80 百分位），将线路分为六档。当日/月/年/时客流量最高的线路独占 Tier 6。

| Tier | 标签 | 线宽 | 颜色 | 说明 |
|------|------|------|------|------|
| 1 | 极度空闲 | 7px | `#feedde` 浅橙 | 客流最低的 20% |
| 2 | 空闲 | 14px | `#fdd0a2` 淡橙 | |
| 3 | 轻度拥挤 | 21px | `#fdae6b` 橙色 | |
| 4 | 中度拥挤 | 28px | `#fd8d3c` 深橙 | |
| 5 | 重度拥挤 | 35px | `#e0551f` 橘红 | 客流最高的 20% |
| 6 | 极度爆满 | 42px | `#8b1a1a` 暗红 | 客流第一的线路独占 |

- 线宽采用 7px 等距递增（7→14→21→28→35→42）
- Tier 6 额外叠加 `stroke-dasharray="40,3"` 虚线双编码
- 所有线路路径端点圆角（`stroke-linecap="round"`、`stroke-linejoin="round"`）

### 3. 时间轴播放与进度条拖拽

- **播放控制**：▶ 播放 / ⏸ 暂停 / ⏮ 后退 / ⏭ 前进
- **速度调节**：0.5x / 1x / 2x / 4x（2000ms ~ 250ms/帧）
- **拖拽进度条**：点击或拖拽圆形手柄可跳转到任意帧
- **渲染优化**：播放期间暂停排名列表刷新，仅更新 SVG 地图和图例

### 4. 潮汐剪刀差图（时模式专属）

时模式下，地图上方显示 Canvas 绘制的双向客流折线图：

- **蓝色线** = inbound（进城方向）
- **橙色线** = outbound（出城方向）
- X 轴 = 18 个时段（5:00-23:00），Y 轴 = 客流量（万人次）
- 点击排名列表中的任意线路切换图表
- 当前选中线路名显示于图表标题区

### 5. 线路客流量排名

地图下方列出当前 28 条线路的客流量排名（从高到低）：

- 名次（前 3 名金色高亮）、线路名、客流量数值（万人次）
- 水平柱状图（宽度与最大值成比例，颜色匹配六档分类）
- 六档颜色圆点标注

### 6. 换乘站压力预警（模块二）

基于 104 个人工标注换乘站坐标（`data/transfer_stations_positions.json`），实时计算并渲染：

- **压力公式**：`avgTier = Σ(途经线路 Tier) / 途经线路数`
- **菱形标记**：黑色外描边 + 彩色菱形 + 脉冲内芯
- **三档预警**：

| 等级 | 阈值 | 颜色 | 菱形半对角线 | 效果 |
|------|------|------|-------------|------|
| 通畅站点 | avg < 4 | `#047857` 绿 | 8px | 静态 |
| 拥堵站点 | 4 ≤ avg < 5 | `#fde725` 黄 | 10px | 脉冲动画 |
| 高压站点 | avg ≥ 5 | `#ff0000` 红 | 20px | 强脉冲 + 光晕 |

- 鼠标悬停显示站点名称和拥堵等级

### 7. 地图 ↔ 排名双向联动（去饱和高亮）

- **选中线路**：保持完整颜色
- **其他所有线路**：统一变为浅灰色（`#c8c8c8`，线宽 2px）
- **排名同步高亮**：对应行高亮

鼠标移开后恢复原始颜色和线宽。地图 hover、排名 hover 双向有效。

### 8. 地图线路悬停 Tooltip

鼠标悬停地图线路时弹出详情卡片，显示线路名称、客流量、当前排名、排名变化（↑↓─）。

### 9. 小多图（Small Multiples）

点击「小多图」按钮，地图上方出现 4×7 CSS Grid，每格一条线路的迷你潮汐图（蓝色=inbound，橙色=outbound），一眼扫过 28 条线路的双向客流形态。

### 10. 山脊图（Ridgeline Plot）

点击「山脊图」按钮，打开全屏 Canvas 叠加层。28 条线路的客流曲线按垂直偏移堆叠如层峦，直观对比各线路在 18 小时内的拥堵分布。

### 11. SVG 细节处理

- 中文 SVG group ID 自动处理 HTML 实体编码（UTF-8 → Windows-1252 映射）
- 站名标签缩放 1.35x（`getBBox()` + wrapper `<g>` 变换）
- 线路名称文字和 "Beijing Subway" 水印自动隐藏

## 数据维度

| 维度 | 字段 | 取值 |
|------|------|------|
| 时间 | date + 5:00-23:00 | 7年 × 12月 × 28-31天 × 18小时 |
| 线路 | lines（28条） | 1号线-八通线 ~ 大兴机场线 |
| 方向 | inbound / outbound | 进城 vs 出城 |
| 场景 | day_type | normal / weekend / holiday / return / exodus |
| 扰动 | weather + event | rain / snow / 演唱会赛事 |

## 数据聚合逻辑

- **时模式**：直接读取 JSON 中对应 hour slot 的 `inbound`/`outbound`/`total` 值
- **日模式**：对该日 18 个 hour slot 的 `total` 求和
- **月模式**：对该月所有日 `total` 求和
- **年模式**：对该年所有日 `total` 求和

## 共线处理

- 13号线与18号线共享 SVG 轨道组 `L13/L18`（物理共线），渲染时取两者客流较大值
- 房山线与燕房线共享 `房山+燕房线`，同理

## 技术亮点

- **rAF 解耦渲染**：播放时定时器只负责调度，实际渲染在 `requestAnimationFrame` 中完成
- **播放期间增量渲染**：仅更新 SVG 线宽和图例，排名列表延迟到暂停后一次性刷新
- **去饱和联动高亮**：选中线路保持原色，其余统一浅灰（`#c8c8c8`），颜色对比强烈
- **换乘站人工标注**：104 个换乘站坐标来自手动标注 JSON，精准可靠，无需 SVG 邻近匹配
- **菱形压力标记**：黑色外描边 + 彩色菱形 + CSS scale 脉冲动画，三档预警清晰可辨
- **中文 ID 乱码处理**：`TextEncoder` → `TextDecoder('windows-1252')` 自动映射 SVG 中文 group ID
- **百分位分类**：等分位（20/40/60/80）线性插值分档，避免极端值偏差
- **Tier 6 双编码**：最高客流线同时使用最大线宽 + 虚线模式，颜色与形状双重区分
