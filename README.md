# MetroFlow — 北京地铁客流量可视化分析系统

## 项目概述

基于北京地铁 SVG 线路图，将 28 条线路 × 2019-2025 年共 2498 天 × 每日 18 小时 × 双向（进城/出城）的客流数据，通过**线宽编码**、**霓虹发光**、**潮汐剪刀差图**、**时间轴动画**等多维可视化手段，构建一个纯前端的交互式客流分析系统。

## 技术栈

纯前端 SPA：HTML + CSS + 原生 JavaScript + Canvas，无框架依赖。通过 `python -m http.server` 即可本地运行。

## 核心功能详解

### 1. 四模式时间粒度

| 模式 | 选择器 | 展示内容 | 播放范围 | 序列长度 |
|------|--------|---------|---------|---------|
| 年 | 年份下拉框 | 某年全线路客流量 | 历年年份（2019-2025） | 7 |
| 月 | 年份下拉框 | 某月全线路客流量 | 当年 1-12 月 | 12 |
| 日 | 月份选择器 | 某日全线路客流量 | 当月每一天 | 28-31 |
| 时 | 日期选择器 | 当日某小时客流量 | 5:00-23:00 | 18 |

切换模式时，播放范围和进度条自动适配。

### 2. 六档线宽编码

基于当日 28 条线路客流值的等分位（20/40/60/80 百分位），将线路分为六档：

| 档次 | 含义 | 线宽 | 颜色 | 说明 |
|------|------|------|------|------|
| 1 | 很低 | 0.5px | 绿色 | 客流最低的 20% |
| 2 | 较低 | 2px | 蓝色 | |
| 3 | 中等 | 5px | 橙色 | |
| 4 | 较高 | 13px | 橙红 | |
| 5 | 很高 | 26px | 红色 | 客流最高的 20% |
| 6 | **最高** | **36px** | 深红 | 当日/月/年/时客流**第一**的线路独占 |

### 3. 霓虹发光效果

所有 tiers 2-5 线路自动应用与其线色一致的 SVG 高斯模糊发光，tier 6（最高）线路发光最强。发光滤镜使用 `userSpaceOnUse` + 完整 SVG 画布坐标，避免大尺寸元素（如 10 号线环线）被裁切。

### 4. 时间轴播放与进度条拖拽

- **播放控制**：▶ 播放 / ⏸ 暂停 / ⏮ 后退 / ⏭ 前进
- **速度调节**：0.5x / 1x / 2x / 4x（2000ms ~ 250ms/帧）
- **拖拽进度条**：点击或拖拽蓝色圆点手柄可跳转到任意帧，拖拽时自动暂停、松手恢复播放
- **渲染优化**：播放期间暂停排名列表刷新（每帧仅更新 SVG 地图和图例），暂停时一次性更新排名

### 5. 潮汐剪刀差图（时模式专属）

时模式下，地图上方显示 Canvas 绘制的双向客流折线图：

- **蓝色线** = inbound（进城方向）
- **橙色线** = outbound（出城方向）
- X 轴 = 18 个时段（5:00-23:00），Y 轴 = 客流量（万人次）
- 早高峰 inbound 冲高、晚高峰 outbound 冲高，形成经典"剪刀"形态
- **点击排名列表中的任意线路**即可切换图表为该线路的双向数据
- 图例标注 "inbound 进城" / "outbound 出城"

### 6. 排名列表（带潮汐方向标签）

地图下方列出当日 28 条线路的客流量排名（从高到低）：

- 名次（前 3 名金色高亮）
- 线路名
- 水平柱状图（宽度与当日最大值成比例，颜色匹配六档分类）
- 客流量数值（万）
- 六档颜色圆点
- **潮汐方向标签**（日/时模式）：
  - `↑ 进城`（早高峰 7:00-8:00 inbound > outbound ×1.3）
  - `↓ 出城`（outbound 占优）
  - `↔ 均衡`

### 7. 场景标签

标题下方自动显示当前日期的场景上下文：

- 日期属性：工作日 / 周末 / 长假·春节 / 返程高峰 / 节前离京
- 天气因子：降雨（蓝色标签）、降雪（白色标签）
- 突发事件：如"五棵松演唱会散场"（红色标签）

年/月模式下不显示（无具体日期）。

### 8. 换乘站标注

SVG 地图上自动检测被 ≥3 条线路经过的换乘站，用白圈蓝边的大圆点标注。鼠标悬停弹出 tooltip：

> 换乘站 · 4条线路
> 1号线-八通线  2号线  6号线  10号线

### 9. 地图 ↔ 排名双向联动高亮

- **地图 → 排名**：hover 地图上某条线路，排名列表中对应行高亮，其他线路变暗
- **排名 → 地图**：hover 排名列表中某行，地图上对应线路保持亮度，其他线路 dim 至 10% 透明度

### 10. 地图线路悬停 Tooltip

鼠标悬停地图线路时弹出详情卡片，显示：
- 线路名称
- 当日客流量（万）
- 当前排名
- 排名变化（相对于上一个时间步的 ↑↓─）

### 11. 视觉细节

- SVG 背景深色（`#111122`），全线文字使用白色 stroke 确保可读
- 所有线路路径端点圆角（`stroke-linecap="round"`）
- 粗线（tiers 3-6）上的白色站台圆圈按比例放大，避免被粗线覆盖

## 数据维度

| 维度 | 字段 | 取值 |
|------|------|------|
| 时间 | date + 5:00-23:00 | 7年 × 12月 × 28-31天 × 18小时 |
| 线路 | lines（28条） | 1号线-八通线 ~ 大兴机场线 |
| 方向 | inbound / outbound | 进城 vs 出城 |
| 场景 | day_type | normal(1647) / weekend(653) / holiday(93) / return(63) / exodus(42) |
| 扰动 | weather + event | rain(364) / snow(124) / 演唱会赛事(183) |

## 数据聚合逻辑

- **时模式**：直接读取 JSON 中对应 hour slot 的 `inbound`/`outbound`/`total` 值
- **日模式**：对该日 18 个 hour slot 的 `total` 求和
- **月模式**：对该月所有日 `total` 求和
- **年模式**：对该年所有日 `total` 求和

## 数据文件说明

`flows_data/bj_subway_flows.json`（约 185MB）包含 2498 天的完整客流数据，单日结构：

```json
{
  "date": "2025-12-31",
  "day_type": "normal",
  "weather": "normal",
  "event": "none",
  "lines": {
    "6号线": {
      "7:00-8:00": { "inbound": 1.08, "outbound": 0.71, "total": 1.79 }
    }
  }
}
```

## 共线处理

- 13号线与18号线共享 SVG 轨道组 `L13_L18`（物理共线），渲染时取两者客流较大值
- 房山线与燕房线共享 `房山_燕房线`，同理

## 技术亮点

- **rAF 解耦渲染**：播放时定时器只负责调度，实际渲染在 `requestAnimationFrame` 中完成，暂停/拖拽即时响应
- **播放期间增量渲染**：仅更新 SVG 线宽和图例，排名列表延迟到暂停后一次性刷新，保证 250ms/帧的流畅度
- **换乘站自动检测**：扫描全部 28 个 SVG 线路组的站点圆坐标，取整聚类后筛选 ≥3 次出现的位置
- **polyline + path 双兼容**：潮汐图和换乘站检测均支持 `<path>`（`getPointAtLength`）和 `<polyline>`（手动分段插值）
